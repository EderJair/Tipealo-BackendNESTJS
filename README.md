# Tipealo-BackendNESTJS

Backend API para Tipealo — SaaS para vendedores de mercados peruanos.

## Stack
- NestJS + TypeScript
- PostgreSQL (Neon)
- TypeORM
- JWT Auth

## Módulos
- Auth (registro/login)
- Clientes
- Productos (con alertas de stock bajo)
- Fiados (cuentas por cobrar, pagos parciales)
- Ventas (descuenta stock automáticamente)
- Dashboard

## Desarrollo
```bash
npm install
npm run start:dev
```

La API corre en `http://localhost:3000/api`
